**Reminder email job**

**Prompt:**

Now implement the booking reminder feature using APScheduler and Resend.

Requirements:
1. A scheduled job runs every hour (configurable via environment variable REMINDER_INTERVAL_HOURS, default 1).
2. The job queries for bookings starting within the next REMINDER_HOURS_BEFORE hours (default 24, from the environment variable).
3. For each booking, check the ReminderSent table. If a reminder has already been sent for this booking, skip it.
4. Send a reminder email via Resend to the member's email address. The email includes: resource name, location, start time, and a cancellation link.
5. After sending, create a ReminderSent row for the booking.
6. Initialise APScheduler in the Flask app factory and start it when the application starts.

Create app/services/reminders.py for the job logic. Update app/__init__.py to initialise and start the scheduler.
