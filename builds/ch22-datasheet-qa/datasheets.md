# Datasheets used in the book

The tool works with any component datasheet, and you will learn more by pointing it at a chip you already know. These are the datasheets used in Chapters 20 and 22, linked at their manufacturers or distributors. They are not included in this repository because they belong to their publishers.

| Component | Used in | Where to get it |
|---|---|---|
| Texas Instruments TMP119 digital temperature sensor | Ch 22: the main test document, and the source of the wrong-chunk retrieval example | <https://www.ti.com/product/TMP119> |
| Micron industrial e.MMC v5.1 (MTFC8GAM to MTFC128GAP) | Ch 22: the table-based question about performance temperature | <https://www.micron.com/products/storage/managed-nand/emmc> |
| Silergy SY8253 3 A synchronous step-down regulator | Ch 22 | <https://www.lcsc.com/product-detail/C93736.html> |
| Microchip ATmega328P | Ch 20: the table extraction example | <https://www.microchip.com/en-us/product/ATmega328P> |

If a link has moved, search the manufacturer's site for the part number. Datasheet revisions change over time, so page numbers in a newer revision may not match the chapter's screenshots.
